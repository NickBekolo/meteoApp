À propos de MétéoApp

MétéoApp est une application web développée avec Angular qui permet de rechercher la météo actuelle d'une ville en interrogeant l'API REST OpenWeather. Ce projet a été réalisé en groupe dans le cadre du module « Angular et communication vers une API ».
